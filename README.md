# Vijay Popuri — Java Backend Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — smooth scrolling and navbar interaction
- `assets/Vijay_Popuri_Resume.pdf` — resume

## GitHub Pages deployment

1. Create a GitHub repository, for example `portfolio`.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Click **Save**.
7. Your site will be available at:
   `https://YOUR-USERNAME.github.io/portfolio/`

## Important

Update the LinkedIn and GitHub URLs in `index.html` before deploying. The resume source only contained the labels "linkedin" and "Github", not their full profile URLs.
